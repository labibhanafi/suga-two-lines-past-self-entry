## What it does

`main.py` writes a two-line warning to your past self into `/output/entry.txt`:

- Line 1 warns the past self about one specific moment — stepping out of Grandpa's hospital room on his last evening to take a call from work.
- Line 2 says why that moment mattered and what changed because of it.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The program is fully deterministic: every run writes the exact same bytes.
